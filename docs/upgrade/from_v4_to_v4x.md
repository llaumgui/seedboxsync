## Upgrade from v4.0 to v4.1

SeedboxSync v4.1 introduces a built-in authentication mechanism.

Once upgraded, you must log in for the first time using the default credentials:

* **Username:** `admin`
* **Password:** `seedboxsync`

After logging in, you can change these credentials or disable the built-in authentication entirely (for example, if you prefer to delegate authentication to a reverse proxy).
